Prototype Write-Up

Initial prototype status for the interactive El Nino Pacific visualization.

What We Have Done So Far

So far, we have built a working GitHub Pages prototype with an interactive Pacific-centered visualization of El Niño-related climate patterns. The page lets users switch between multiple data layers, including a combined El Niño signal, SST warming, rainfall shift, cloud cover, and radiation. We also added overlays for the Niño 3.4 box and Pacific regions so users can connect the map to the climate definition of El Niño. The visualization loads data from a shared JSON file generated from CESM2 historical CMIP6 data and updates the map when users click different layers. We have also started refining the explanatory text so the project communicates how multiple ocean-atmosphere effects relate to one another.

What Will Be Most Challenging

The hardest part will be combining multiple weather effects into one visualization without making the map confusing. Temperature, rainfall, cloud cover, radiation, and wind use different units and visual encodings, so we need to design toggles and annotations carefully. Another challenge is making the guessing game feel meaningful instead of gimmicky; the guesses should connect directly to what the visualization reveals. It will also take work to make the combined signal understandable so users know what each layer contributes. The final design needs to stay simple enough for someone unfamiliar with El Niño while still showing enough data to make the pattern convincing.
