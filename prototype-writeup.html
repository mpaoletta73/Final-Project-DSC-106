Prototype Write-Up

Initial prototype status for Guess the El Nino Effect, an interactive prediction-and-reveal explanation of Pacific climate changes.

What We Have Done So Far

So far, we have built a working GitHub Pages prototype with an interactive Pacific-centered visualization of El Niño-related climate patterns. The current page already loads a shared JSON dataset generated from CESM2 historical CMIP6 data and renders it as a browser-based map. Users can switch between multiple climate layers, including a combined El Niño signal, sea surface temperature warming, rainfall shift, cloud cover, and radiation. We also added overlays for the Niño 3.4 box and western, central, and eastern Pacific regions so users can connect the map to the climate definition of El Niño. The combined signal is our bridge to the final concept because it gives users one reveal view that can summarize how several ocean-atmosphere effects line up. In the final version, users will first make predictions about the Pacific warming pattern and then compare those expectations with the actual mapped signal.

What Will Be Most Challenging

The hardest part will be turning the current explorable map into a prediction-based interaction that feels meaningful instead of gimmicky. The questions need to ask users about effects they can actually verify when the map is revealed, such as where the Pacific warms most, how rainfall changes, and which effect is clearest. Temperature, rainfall, wind, and combined effects use different units and visual encodings, so the final layer toggles and annotations need to be designed carefully. It will also take work to find or prepare compatible wind data for the same regions and time periods used by the current CMIP6 layers. The final design needs to stay simple enough for someone unfamiliar with El Niño while still showing that the pattern is a connected Pacific-wide climate signal, not just warmer ocean water.
