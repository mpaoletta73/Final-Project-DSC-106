The map is drawn from one shared JSON data file generated from CESM2 historical CMIP6 data. Buttons change the encoded variable inside the same Pacific coordinate system; the timeline below stays linked to the Nino 3.4 index used to define El Nino-like months. This combined view is the foundation for the final reveal: users will eventually make predictions first, then compare those guesses against the mapped climate signal.
