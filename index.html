El Nino is a system, not a single warm patch.

This project compares El Nino-like months against neutral months using CESM2 historical CMIP6 data from 1950-2014. The map shows a composite pattern, not a year-by-year animation.

The goal is to see how ocean warming connects with rainfall, cloud cover, and outgoing shortwave radiation across the Pacific. Start with the El Nino fingerprint, then peel apart the variables.
